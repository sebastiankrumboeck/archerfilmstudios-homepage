# Frame & Motion Photography Club Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved Frame & Motion single-page photography and motion club site as a responsive vanilla HTML page styled with Tailwind CSS and served by Vite.

**Architecture:** Keep the complete page in semantic `index.html` so it remains readable without JavaScript. Use Tailwind utility classes in the markup, shared tokens and progressive-enhancement rules in `src/input.css`, and only mobile-menu and image-fallback behavior in `src/main.js`. The mobile menu and image error states enhance an already functional static page.

**Tech Stack:** Vite, Tailwind CSS 4 through `@tailwindcss/vite`, vanilla HTML/CSS/JavaScript, Google Fonts, Vitest with jsdom, and ESLint flat configuration.

---

## Scope and file map

The workspace currently contains only the approved design specification and is not a Git repository. The following files are created for the implementation:

- `package.json` — project metadata and `dev`, `build`, `preview`, `lint`, and `test` scripts.
- `package-lock.json` — npm dependency lockfile generated by the install step.
- `vite.config.js` — Vite and Tailwind plugin configuration.
- `vitest.config.js` — jsdom test environment and test file pattern.
- `eslint.config.js` — flat ESLint configuration for JavaScript files.
- `.gitignore` — dependency, build, and visual-companion exclusions.
- `index.html` — semantic page structure and static content.
- `src/main.js` — mobile-menu and image-fallback progressive enhancement exports and initialization.
- `src/input.css` — Tailwind import, Google Fonts, theme tokens, base rules, and component rules.
- `tests/page.test.js` — static markup and content contract tests.
- `tests/main.test.js` — menu and image-fallback behavior tests.

Do not add React, a component framework, a backend, a form handler, a CMS integration, local image assets, or a runtime gallery data loader. If Git is initialized before implementation, use the conditional commit steps in each task; do not initialize Git solely for this plan.

```js
  const button = document.createElement('button');
  button.type = 'button';
  button.setAttribute('aria-expanded', 'false');
  button.setAttribute('aria-controls', 'mobile-navigation');
  button.setAttribute('aria-label', 'Open navigation menu');

describe('mobile menu enhancement', () => {
  it('starts closed and updates its accessible state when toggled', () => {
```

```js
import './input.css';

export function setMenuState(button, navigation, isOpen) {
  button.setAttribute('aria-expanded', String(isOpen));
  button.setAttribute('aria-label', isOpen ? 'Close navigation menu' : 'Open navigation menu');
  navigation.dataset.open = String(isOpen);
}

export function bindMenu(button, navigation) {
  if (!button || !navigation) {
    return () => {};
  }

  let isOpen = false;
  const update = (nextOpen) => {
    isOpen = nextOpen;
    setMenuState(button, navigation, isOpen);
  };
  const onToggle = () => update(!isOpen);
  const onNavigationClick = (event) => {
    if (event.target instanceof Element && event.target.closest('a')) {
      update(false);
    }
  };
  const onKeydown = (event) => {
    if (event.key === 'Escape' && isOpen) {
      event.preventDefault();
      update(false);
      button.focus();
    }
  };

  update(false);
  button.addEventListener('click', onToggle);
  navigation.addEventListener('click', onNavigationClick);
  document.addEventListener('keydown', onKeydown);

  return () => {
    button.removeEventListener('click', onToggle);
    navigation.removeEventListener('click', onNavigationClick);
    document.removeEventListener('keydown', onKeydown);
  };
}

export function bindImageFallbacks(root = document) {
  const handlers = new Map();
  const images = [...root.querySelectorAll('[data-fallback-image]')];
  const failImage = (image) => {
    image.hidden = true;
    image.closest('[data-image-frame]')?.classList.add('is-fallback');
  };

  for (const image of images) {
    const onError = () => failImage(image);
    handlers.set(image, onError);
    image.addEventListener('error', onError, { once: true });
    if (image.complete && image.naturalWidth === 0) {
      onError();
    }
  }

  return () => {
    for (const [image, onError] of handlers) {
      image.removeEventListener('error', onError);
    }
  };
}

if (typeof document !== 'undefined') {
  document.documentElement.classList.add('js');
  bindMenu(
    document.querySelector('[data-menu-toggle]'),
    document.querySelector('[data-mobile-nav]'),
  );
  bindImageFallbacks();
}
```
